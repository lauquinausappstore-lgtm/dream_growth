# 小六夢想成長 Prompt 生成器

供學生在 iPad Safari 使用的繁體中文靜態網頁。無需安裝、API Key 或建置步驟。

## GitHub Pages 發佈

1. 建立 GitHub repository（例如 `dream-growth-ipad`）。
2. 將 `index.html` 和 `.nojekyll` 上傳至 repository 根目錄。
3. 開啟 Settings → Pages。
4. 在 Build and deployment 選擇 Deploy from a branch，分支選擇 main、資料夾選擇 / (root)，儲存。
5. 等候部署完成，使用 Pages 顯示的 HTTPS 網址。

## iPad 使用

在 Safari 開啟網站網址，填寫關鍵字，再按「複製完整 Prompt」。可經 Safari 分享選單選擇「加入主畫面」。各裝置獨立使用，表單資料不會同步。

網頁在裝置上產生提示詞；不含相片上傳功能或外部程式依賴。使用圖片生成平台時，請依從學校及家長的授權安排。
